# Radius

모서리 반경 토큰. 요소 크기에 비례해 선택한다 — 작은 요소일수록 작은 반경.

`--radius-2xl`은 **96px이 넘는 큰 정사각 아이콘**을 위한 것이다(2026-09-14에 더했다).
완주 화면의 테마 아이콘(120px)처럼, 앱 아이콘으로 읽혀야 하는 자리다. 모달·바텀시트는
그보다 작은 `--radius-xl`이다. 알약 모양과 원형은 크기와 무관하게 `--radius-full`이다.
