# Color — Semantic

역할 기반 토큰. 네이밍 패턴: `분류-용도`. 컴포넌트는 이 토큰만 참조한다.

**"참조 팔레트" 칸은 이 토큰이 실제로 무엇을 가리키는지다.** 컴포넌트에서 팔레트를
직접 쓰지 말라는 규칙이 있어 평소에는 몰라도 되지만, 새 토큰을 정할 때 옆 토큰이
어느 단계를 쓰는지 보면 고르기가 쉽다.

## Background

<BgColorTable />

`bg-overlay-blur`는 `bg-overlay`의 흰 블러 버전이다. 검정 딤은 그 위 버튼·글자가
잘 안 보인다는 지적이 있어서 만들었다 — 이미지처럼 밝기를 예측할 수 없는 콘텐츠를
전체 화면으로 덮을 때 쓴다. 아래처럼 `--blur-overlay`(backdrop-filter 값)와 항상
함께 쓴다:

```css
background: var(--color-bg-overlay-blur);
backdrop-filter: blur(var(--blur-overlay));
-webkit-backdrop-filter: blur(var(--blur-overlay));
```

**언제 쓰나** — 콘텐츠(이미지 등)에 시선을 집중시키고 싶을 때 쓴다. LayerPopup
(모달·바텀시트) 같은 기능적 overlay와는 맥락이 다르다 — 그쪽은 어떤 화면에서든
쓰는 범용 그릇이라 `--color-bg-overlay`(검정)를 그대로 쓰고 바꾸지 않는다.

**레이아웃 규칙**
- 우상단엔 항상 닫기 버튼을 둬서, 언제든 페이지를 벗어날 수 있게 한다.
- 좌상단엔 보조로 필요한 기능(삭제 등)을 둔다. 없으면 비워둔다.
- 위 두 자리는 IconButton을 쓴다 — 텍스트 버튼은 라벨 길이가 다 달라 두 자리가
  서로 안 맞고, 콘텐츠에 집중시키는 화면에서 글자가 이미지보다 눈에 먼저 들어온다.
