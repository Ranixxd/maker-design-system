# Typography

텍스트 스타일 프리셋. CSS 클래스(`.text-*`)로 제공되며, `font-size` · `font-weight` · `line-height`를 묶어서 정의한다.

**`--font-size-*` `--font-weight-*` `--line-height-*` 낱개 토큰을 컴포넌트에서 직접 쓰지 않는다.**
반드시 아래 클래스 세트 중 하나를 선택해서 쓴다.

```jsx
{/* ✅ JSX에서 글로벌 클래스로 */}
<span className="text-label-sm">라벨</span>
```

```css
/* ✅ CSS Module에서 composes로 */
.title {
  composes: text-heading-md from global;
}

/* ❌ 낱개 토큰 직접 참조 — 금지 */
.title {
  font-size: var(--font-size-2xl);
  font-weight: var(--font-weight-semibold);
}
```

---

## 세 묶음을 가르는 기준

| 묶음 | 언제 | 가르는 질문 |
|---|---|---|
| **heading** | 화면이나 덩어리의 **이름** | "무엇에 대한 화면·창인가"를 말하나? |
| **body** | **읽는 글.** 두 줄 이상으로 꺾일 수 있다 | 문장인가? |
| **label** | **누르거나 가리키는 짧은 이름표.** 한 줄에서 끝난다 | 버튼·탭·칩·입력칸 이름처럼 한 줄로 끝나나? |

## 정해 둔 것 (2026-09-17)

**클래스를 새로 만들지 않는다.** 위 열한 개 안에서 고른다. 딱 맞는 단계가 없어 보여도
가장 가까운 것을 쓴다. 단계가 늘면 어느 것을 골라야 할지가 다시 흐려진다.

**작은 제목은 `heading-xs`다.** 처음에는 열 개로 두고 작은 제목을 `label-md`로 보내기로 했다.
그런데 카톡테마 메이커에 적용하며 보니 제목으로 쓰던 굵은 글(600·700)이 스무 곳 넘게
label로 가면서 500으로 가벼워져 본문과 구분이 약해졌다. 그래서 이것 하나만 더했다
(15px·600·1.3, 2026-09-17). 이것이 유일한 예외다.

**heading은 줄 간격이 1.3이다.** 처음에는 label과 같은 1이었는데, 모바일에서 제목이 두 줄로
꺾이면 줄이 붙었다. 줄 간격 값(`--line-height-heading`)만 더했고 클래스는 늘리지 않았다.
label은 한 줄에서 끝나니 1 그대로다.

**입력칸 글자는 `body-md`(15px)다.** 아이폰 자동 확대를 피하려고 16px로 올리지 않는다.
확대는 쓰는 쪽 페이지의 viewport가 막는다(UI/TextField 문서).
