# Design Tokens

컴포넌트와 레이아웃에서 사용하는 모든 디자인 결정의 원천입니다.
`src/tokens/` 에 CSS custom property로 정의되어 있습니다.

카테고리별 상세 토큰은 사이드바에서 확인하세요.

| 카테고리 | 설명 |
|---|---|
| Color | Primitive 팔레트 (gray, sky, black, white) |
| Semantic Color | 역할 기반 컬러 (bg / text / border / icon) |
| Typography | 텍스트 스타일 프리셋 (.text-*) |
| Spacing | 4px 그리드 기반 여백 토큰 |
| Radius | 모서리 반경 |
| Shadow | 그림자 레이어 |
| Motion | 이징·듀레이션 토큰 및 조합 가이드 |
