# Color — Primitive

팔레트 원형 토큰. **`colors.css` 내부에서 시멘틱 토큰을 정의할 때만 쓴다.**
컴포넌트나 레이아웃 CSS에서 직접 참조하면 안 된다.

```css
/* ❌ 컴포넌트에서 직접 참조 — 금지 */
color: var(--color-gray-500);
background: var(--color-sky-100);

/* ✅ 시멘틱 토큰을 통해 참조 */
color: var(--color-text-secondary);
background: var(--color-bg-accent-subtle);
```
